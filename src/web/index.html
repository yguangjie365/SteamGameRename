Write To Cache

应用写入

将把 0 条已批准的名称写入 Steam 分片文件。

写入前请完全关闭 Steam 客户端（含托盘图标）。

通过 steam.exe -shutdown 优雅退出，不强制结束进程；20 秒内未退出则中止写入。

程序会先备份原文件；任何校验失败都会自动回滚。
