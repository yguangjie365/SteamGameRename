应用写入确认

将把 0 条已批准的名称写入 Steam 分片文件。

写入前请完全关闭 Steam 客户端（含托盘图标）。

通过 steam.exe -shutdown 优雅退出，不强制结束进程；若 20 秒内未退出则中止写入。

程序会自动备份原文件；若校验失败将自动回滚。

从备份恢复

恢复会用备份中的分片覆盖当前 APPCache\APPInfo，请先关闭 Steam。
